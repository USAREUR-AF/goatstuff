FLEET DIAGNOSTICS

LIVE STATE

What this browser session is seeing right now. Refreshes once a second while this overlay is open.

  • tier— — perf state driving polling cadences + viz fidelity (see PERF TIERS).
  • ws— — WebSocket delta-stream state. Drives the top-bar connection indicator (open · live / open · quiet / reconnecting / closed).
  • last event— — time since the last delta event arrived over the WS. Past 10 s the indicator dims to live · quiet.
  • snapshot poll— — current /api/snapshot HTTP cadence; tier-gated.
  • stale threshold— — past this age the sidebar shows STALE. 4× the current poll interval.
  • running— — image SHA the backend is running. Matches ghcr.io/usareur-af/panoscope:sha-<short>.

WHAT EACH METRIC MEANS

Definitions for the five compact counters on the fleet-stats sidebar — what gets counted, what doesn't.

  • PEERSDistinct application peers in the current snapshot. Excludes topic-virtual nodes (the broker pins). Source: /api/snapshot nodes where role !== "topic".
  • TOPICSUnique key_expr strings from snapshot edges. Server-side singleton fold counts each fold-group as ONE entry (a 1898-entity vendor-c namespace = 1 here, not 1898). Source: distinct snap.edges[].topic.
  • MSG/SFleet aggregate publish rate. Sum of per-edge projected_eps: events counted per one-second bucket, smoothed by an exponential moving average (time constant in the diag panel). A count, not an average of one-over-gap — the latter reads a bursty publisher at ~3× its rate. Matches the fabric-health meter on /top. Source: sum(snap.edges[].projected_eps) over unique (source, topic).
  • TOTALCumulative samples observed since container start. Survives restart via MinIO audit-replay over the last 168 h. Source: /api/stats.data_samples_recorded. Hover the value to see full-precision count.
  • __LEX_ORGS_UPPER__Distinct logical-__LEX_ORG__ names. Prefers schema-decl vendor field; falls back to peer_id prefix for partner peers that don't carry a schema-decl. Source: derived from snap.nodes.

HOW THIS UPDATES

Cadences + safety rails between the backend and this browser tab. Explains the otherwise-invisible plumbing behind the numbers.

  • snapshotOne HTTP fetcher (this sidebar's poll, tier-cadenced); canvas renderer + welcome panel subscribe to the same fetch via an in-page pub/sub bus. No fan-out fetch storms on the connection pool.
  • snapshotPollMsTier-gated HTTP poll cadence: LIVE 1500 ms · SLOW 3000 ms · DEGRADED 5000 ms · AUSTERE 30000 ms.
  • streamPollMsSide-panel decoded-sample stream refresh: LIVE 250 ms · SLOW 750 ms · DEGRADED 10 s · AUSTERE manual only.
  • WS coalesce100 ms server-side delta-batching: the browser receives at most one delta payload per 100 ms regardless of underlying publish rate.
  • fetch timeoutHard 8 s per HTTP request via AbortSignal.timeout(). Past this the fetch aborts; the freshness gate treats it as one failure. Caps the wait so a hung backend can't hold a connection slot.
  • freshness gateSidebar shows STALE when either: (a) two consecutive HTTP refresh attempts failed, or (b) snapshot age > 4× the current poll interval.
  • EMA τtime constant for the per-edge projected_eps moving average (value in the diag panel below). Each closed one-second bucket folds its count into the average; a topic that just spiked from 0 to 10 evt/s reads ~6.3 evt/s after one τ.

PERF TIERS (what changes)

Each tier answers a specific kind of "broken or just busy" — they surface degradation instead of leaving a frozen-looking viz with no explanation. Italic on-screen notes describe what you'd see on the live page.

  • LIVEFull fidelity: packet-dot animation + force layout + fast polling. Triggers: browser sustaining frame budget under render load. On-screen: no banner; tier badge reads LIVE.
  • SLOWPacket-dots off (edge thickness EMA still encodes flow). Force-sim stays. Slower poll. Triggers: frame budget under load. On-screen: tier badge reads SLOW; packet-dot layer empty.
  • DEGRADEDAlso drops force-sim; topology renders static. Slowest polling tier with values still updating. Triggers: heavy frame-drop. On-screen: tier badge reads DEGRADED; nodes don't drift on idle.
  • AUSTEREDrops polling (manual refresh only) AND strips visualization to topology skeleton + the operator's selected slice (hides unselected edges + hull fills + the packet-dot layer). On-screen: tier badge reads AUSTERE; canvas shows only the selected slice + skeleton.
  • WATCHFULNot a separate tier — a top-bar badge that explains the packet-dot rate-gate hiding dots when fleet aggregate is 50-200 msg/s AND nothing is selected. Select an edge or peer to see its slice. On-screen: WATCHFUL badge in top bar; viz looks empty until you select.

READING THIS COP

NODES

  • SOURCE publishes only — sensors, raw producers
  • DERIVER consumes upstream AND publishes derived output — fusion, correlation, translation, C2
  • SINK subscribes only — operator displays, archives, audit logs
  • TOPIC broker pin between publishers and subscribers (one per published keyexpr)
  • INFRASTRUCTURE underlying substrate, not an application data participant — Zenoh router, observer subscriber (e.g. audit), schema-registry / operator-system publisher, or chaos generator (trashgoat). All share the desaturated fill so they read as one class; the glyph (square for the router, star for chaos, role-shape otherwise) says which kind. The infra fleet toggle shows / hides / isolates them as a group.
  • __LEX_ORG_UPPER__ SUPER collapsed __LEX_ORG__ — chunky rounded panel labelled "__LEX_ORG_UPPER__ Np·Mt" (peer + topic counts). Replaces every peer and intra-__LEX_ORG__ topic of the __LEX_ORG__ with one glyph; cross-__LEX_ORG__ edges land on this. Double-click (or the side-panel button) expands it back to peers; double-click a __LEX_ORG__'s cluster to collapse it. Mass collapse / expand via the fleet-bar COLLAPSE ALL / EXPAND ALL buttons.
  • SINGLETONS SUPER a high-cardinality fan-out folded into one box — when a publisher emits many sibling topics (e.g. one per entity / UUID), the whole pile collapses to this stacked-disc glyph so it doesn't drown the canvas. Hover to see the folded count (and a slow-browser warning if large); click to open the namespace inspector (a searchable list of the folded topics, with a "show on canvas" button for small groups). The publishing peer carries a darker inner dot while folded.

HEADER + INDICATORS

  • TIER badgebrowser-performance tier (LIVE / SLOW / DEGRADED / AUSTERE). Drives polling cadence + animation gating so the COP stays functional under load.
  • WATCHFUL badgeappears in the top bar when fleet rate (50-200 msg/s) is gating packet-dot animation to selection — meaning "select an edge to see its flow." Without this badge an apparently-frozen viz is fabric-quiet; with it, the viz is degrading gracefully.
  • STALE counterswhen the fleet-bar refresh has failed twice or is older than 2× the poll interval, the left-sidebar counters desaturate and the freshness tag turns red. Distinguishes "fabric is calm" from "we lost the data connection."
  • AUSTERE stripat the AUSTERE tier, all unselected edges + hull fills + the dot layer are hidden so the topology skeleton + the operator's selected slice are the only things on screen. What remains is true and live; the rest was load the device couldn't render.
  • SOURCE toggle3-way: ALL → REAL ONLY → NOTIONAL ONLY → ALL. REAL hides synthetic publishers (keeps admin-discovered routers / subscribers); NOTIONAL shows only synthetic peers; ALL is the default mixed view
  • INFRA toggle3-way: SHOW ALL → HIDE INFRA → ONLY INFRA → SHOW ALL. HIDE drops every infrastructure node (router, observer subscriber, schema-registry, operator-system, chaos) so only application data participants remain; ONLY isolates the substrate. Orthogonal to SOURCE — the two compose.
  • COLLAPSE ALL / EXPAND ALLmass folds / unfolds every __LEX_ORG__ in the snapshot. Per-__LEX_ORG__ toggles still work after: double-click a __LEX_ORG__'s cluster to collapse it, double-click the resulting super-node to expand it (or use the side-panel button on either). Single click always just selects.
  • SYNTHETIC badgeper-peer indicator that the data is notional, not operational
  • FUTURE DESIGN clusterdesaturated gray hull + "FUTURE DESIGN · NOT ACTIVE ON THIS FABRIC" subtitle marks clusters whose top-level prefix is reserved on the long-term fabric but not lit up here. Currently attest/** — the schema-decl heartbeat surface; the goat-zenoh-portal serves the schema-registry role on this fabric as a facilitation expedient.
  • node_kindsubstrate-level kind learned from the Zenoh admin namespace — router / peer / subscriber. Schema-decl peers carry richer logical metadata (vendor, site, role_class); admin-only peers (Zenoh router, audit-subscriber) carry node_kind alone
