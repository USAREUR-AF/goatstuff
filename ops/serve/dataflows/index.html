Opening Every Integration Is a Wire Choice
  • The right pattern scales. The wrong one rots quietly.
  • Four families cover the field: internal-only, ICDs, APIs, event-driven.
  • Each is right somewhere. None is right everywhere.

The Patterns APIs — When They're Right, When They Aren't
  • Right: banking, billing, lookups, CRUD on a record — stable contract, known counterparty, one authoritative source.
  • Wrong: perishable data, fan-out to unknown consumers, partition-tolerant operation — anywhere "ask and wait" misses the moment.

Event-Driven Decoupled in Time, Identity, Cardinality
  • Family: sockets, message queues, streams, pub/sub fabrics — producers emit, fabric carries, consumers subscribe.
  • Contract moves from the wire to the topic + schema. Late joiners can replay. Partitioned sites keep flowing locally.
  • Cost: schema discipline — published, versioned, evolved — or the fabric becomes a swamp.
Where We're Headed GOAT-Net — Event-Driven by Default
  • The data fabric is pub/sub (Zenoh) inside an identity-bound mesh. Every system integrates once.
  • Legacy ICD systems stay — behind a shim that translates their wire to topics on the fabric.
  • APIs belong on control-plane CRUD; pub/sub belongs on data in motion.
  • Island mode is the default: WAN dies, local pubs keep flowing. Link returns, fabric reconciles.
